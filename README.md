# Gothic-1-Remake-UE4SS-Enabler
A compatibility patcher for Gothic 1 Remake that helps restore UE4SS mods support after a game update from 10/29/2026 (Build102_CL175960).

G1R UE4SS Patcher is a lightweight patcher for Gothic 1 Remake that adjusts executable checks preventing UE4SS mods from working after a game update.

It automatically locates the game executable, checks compatibility, and applies the patch when needed. A backup of the original executable is created before any changes are made.


## Installation
Steps
1.	Download the repository and extract the archive.
2.	Locate your game folder. The usual path is:
C:\STEAM\steamapps\common\Gothic 1 Remake\G1R\Binaries\Win64
3.	Copy all files from the repository into the Win64 folder, preserving the directory structure. If Windows asks to merge folders, allow it.
4.	Run RunPatch.cmd from the Win64 folder. Make sure the game is closed first.
5.	Follow the on-screen instructions. The patcher automatically locates the game executable, checks whether a patch is needed, and creates a backup before modifying the file.
6.	Launch the game and check that UE4SS mods works correctly.
